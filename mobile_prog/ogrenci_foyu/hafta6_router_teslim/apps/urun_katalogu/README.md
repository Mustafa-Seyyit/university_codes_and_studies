# Mini Ürün Kataloğu

Bağımsız Expo SDK 57 / Expo Router projesi; uygulama JavaScript/JSX kullanır.

Depodaki ortak kurulum için kökte `npm ci`, bu klasörde `npm start` veya `npm run web` çalıştırın. Tek başına kopyaladıysanız bu klasörde `npm install` çalıştırın.

Kontroller: `npm run lint`, `npm run typecheck`, `npm run export`.

Tüm teslim belgeleri ve gerçek test sonuçları [ana README](../../README.md) ve [docs](../../docs/) klasöründedir.
